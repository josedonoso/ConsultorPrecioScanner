# Consultor Precio Scanner

Aplicación web desarrollada en ASP.NET Core MVC para consultar precios mediante escaneo de código de barras desde la cámara del teléfono.

## Funcionalidades

- Escaneo de código de barras con cámara
- Consulta rápida de precios
- Formato de precio chileno
- Modo oscuro
- Panel para agregar productos
- Edición automática si el producto ya existe
- Base de datos SQL Server
- Publicación en hosting Somee(Gratuito)
- Deploy automático desde GitHub Actions

## Tecnologías

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- HTML, CSS y JavaScript
- html5-qrcode
- GitHub Actions
- Somee Hosting

## Uso

1. Abrir la aplicación web.
2. Permitir acceso a la cámara.
3. Escanear el código de barras.
4. Ver el precio del producto en pantalla.

## Objetivo

Este proyecto fue creado como una herramienta personal de apoyo para consultar precios rápidamente en caja cuando sea necesario recordar el valor de un producto.
